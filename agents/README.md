# 🤖 AI-агенты для бизнеса по камню

Команда из четырёх AI-агентов на Claude, которые живут в вашей Telegram-группе,
помогают вести бизнес, **общаются между собой, учатся друг у друга** через общую
базу знаний и **ставят вам задачи**.

| Агент | Роль |
|-------|------|
| 💬 **Алина** | Общение с клиентами: готовые ответы, скрипты продаж, ведение сделки |
| 📣 **Марк** | Таргетированная реклама: креативы, тексты объявлений, аудитории, бюджеты |
| 🔎 **Стас** | Поиск объектов: новостройки, отели, дизайнеры, архитекторы, тендеры |
| 📦 **Борис** | Снабжение: поставщики камня, цены, инструмент, расходники, логистика |

## Что они умеют

- **Отвечают в группе** — пишете вопрос, диспетчер сам решает, чья это зона, или
  обращаетесь по имени: «Марк, придумай рекламу каминов на зиму».
- **Советуются друг с другом** — Стас нашёл объект → сам спрашивает Алину, как
  написать первое сообщение. Вся переписка агентов видна в группе.
- **Учатся друг у друга** — каждый агент записывает уроки в общую базу знаний
  (`save_lesson`), и все остальные видят их в своём контексте.
- **Ставят вам задачи** — «позвонить дизайнеру», «согласовать бюджет рекламы».
  Список: `/tasks`.
- **Ищут в интернете** — Марк, Стас и Борис используют веб-поиск (конкуренты,
  объекты, поставщики) со ссылками на источники.
- **Планёрки по расписанию** — утром каждый агент предлагает план на день,
  вечером приходит отчёт по задачам и новым урокам.

## Команды в чате

| Команда | Что делает |
|---------|------------|
| `/help` | Список агентов и подсказки |
| `/tasks` | Открытые задачи |
| `/lessons` | База знаний (последние уроки) |
| `/standup` | Провести планёрку прямо сейчас |

## Установка за 5 шагов

Нужен Node.js 20+ и два ключа: Claude API и Telegram-бот.

### 1. Создайте Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя.
2. Сохраните токен (`123456789:AA...`).
3. **Важно:** выключите режим приватности, иначе бот не видит сообщения в группе:
   `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off**.

### 2. Создайте группу

1. Создайте Telegram-группу (например «Starpass — команда AI»).
2. Добавьте туда бота.
3. Напишите в группу любое сообщение, затем откройте в браузере
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` — найдите
   `"chat":{"id":-100...}`. Это `TELEGRAM_GROUP_ID`.

### 3. Получите ключ Claude API

[platform.claude.com](https://platform.claude.com) → API Keys → Create Key.

### 4. Настройте и запустите

```bash
cd agents
cp .env.example .env     # впишите ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_GROUP_ID
npm install
npm start
```

В консоли появится `✅ Бот @... запущен` — напишите в группу `/help`.

### 5. Запуск 24/7 — Railway.app (рекомендуется)

Railway запускает бота как постоянный процесс, деплой прямо из GitHub.
Стоимость — план Hobby $5/мес (включает $5 ресурсов; этому боту хватает).

**Шаг 1. Создайте проект**

1. Зайдите на [railway.app](https://railway.app) и войдите через GitHub.
2. **New Project → Deploy from GitHub repo** → выберите этот репозиторий
   (при первом разе Railway попросит доступ к репозиторию — разрешите).

**Шаг 2. Укажите папку сервиса**

В сервисе откройте **Settings → Source → Root Directory** и впишите:

```
agents
```

Railway сам найдёт `railway.json` и `package.json`, соберёт и запустит
`npm start`. Публичный домен не нужен — это фоновый процесс без HTTP.

**Шаг 3. Подключите постоянный диск (обязательно!)**

Память агентов (задачи, база знаний) хранится в файле, а диск Railway
очищается при каждом деплое. Поэтому:

1. Правый клик по сервису → **Attach Volume** (или Settings → Volumes).
2. Mount path: `/data`.

**Шаг 4. Переменные окружения**

Вкладка **Variables** сервиса → добавьте:

```
ANTHROPIC_API_KEY=sk-ant-...
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_GROUP_ID=-100...
DATA_DIR=/data
TIMEZONE=Europe/Rome
```

(остальные — по желанию, см. `.env.example`)

**Шаг 5. Деплой и проверка**

Railway задеплоит автоматически после сохранения переменных. Откройте
вкладку **Deployments → View Logs** — должно появиться:

```
✅ Бот @ваш_бот запущен. Модель: claude-sonnet-5
⏰ планёрка вручную (/standup), отчёт в 19:00 (Europe/Rome)
```

Напишите в группу `/help` — агенты на связи. Дальше каждый push в ветку
будет автоматически передеплоивать бота (память в `/data` сохраняется).

> ⚠️ Держите ровно **один** запущенный экземпляр (Replicas = 1, по
> умолчанию так и есть). Два экземпляра будут отбирать друг у друга
> сообщения Telegram.

### Альтернатива: свой сервер (VPS)

Через [pm2](https://pm2.keymetrics.io/):

```bash
npm install -g pm2 tsx
cd agents && npm install
pm2 start "npm start" --name agents
pm2 save && pm2 startup
```

## Настройка под себя

Всё в `.env` (см. `.env.example`):

- `BUSINESS_PROFILE` — опишите свой бизнес своими словами: рынки, услуги,
  клиенты. Агенты строят все ответы вокруг этого описания.
- `MORNING_HOUR` — задайте час (например `9`), чтобы включить ежедневную
  утреннюю планёрку; по умолчанию она выключена — используйте `/standup`.
- `EVENING_HOUR` / `TIMEZONE` — час вечернего отчёта и часовой пояс.
- `AGENT_MODEL` — модель Claude: `claude-sonnet-5` (по умолчанию, быстро и
  недорого) или `claude-opus-4-8` (максимум ума, дороже).
- `AGENT_EFFORT` — `low` (по умолчанию) / `medium` / `high` — вдумчивость.

Характеры и обязанности агентов правятся в `src/agents.ts` — это обычный текст.

## Как это устроено

```
Telegram-группа
      │  (long polling)
      ▼
 Диспетчер (Claude) — решает, чей это вопрос
      ▼
 Агент (Claude + инструменты)
   ├─ save_lesson    → общая база знаний (учатся друг у друга)
   ├─ create_task    → задачи владельцу
   ├─ ask_agent      → вопрос коллеге (его ответ виден в группе)
   └─ web_search     → поиск в интернете (Марк, Стас, Борис)
      ▼
 Ответ в группу от имени агента
```

Память хранится в `agents/data/db.json` (задачи, уроки, история чата) — при
переносе на сервер заберите этот файл с собой.

> В Telegram боты не видят сообщения других ботов, поэтому «четыре отдельных
> бота» не смогли бы разговаривать между собой. Здесь один бот и четыре
> личности — агенты реально обмениваются вопросами и ответами внутри одной
> системы, а переписка публикуется в группу.

## Стоимость

Каждый ответ агента — это запросы к Claude API. На модели по умолчанию
(`claude-sonnet-5`) один вопрос с веб-поиском ≈ $0.02–0.12; повторяющиеся
части запросов кэшируются автоматически (~10% цены). Планёрка `/standup` —
4 запроса, вечерний отчёт бесплатный. Максимальное качество —
`AGENT_MODEL=claude-opus-4-8` (в ~2.5 раза дороже). Поставьте лимит расходов
на platform.claude.com → Settings → Limits.
